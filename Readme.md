# NetGuard AI - Cyber Threat Detection System

A full-stack machine learning-powered network threat detection and anomaly analysis system built with Node.js and vanilla JavaScript.

## Features

✅ Real-time network threat detection
✅ Dual ML model pipeline (XGBoost + Isolation Forest)
✅ CICIDS2017 dataset feature extraction
✅ Attack classification & anomaly detection
✅ Beautiful modern dashboard
✅ User authentication & session management
✅ Event history & statistics
✅ Mock mode for testing
✅ Production-ready Vercel deployment

## Tech Stack

- **Frontend**: HTML5, CSS3, Vanilla JavaScript
- **Backend**: Node.js (24.11.1), Express.js
- **Database**: SQLite (better-sqlite3)
- **Authentication**: HMAC-signed JWT tokens
- **Deployment**: Vercel
